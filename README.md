# 🚗 Car Life Prediction Model

This is a beginner-friendly machine learning project that predicts the
remaining useful life of a car based on average kilometers driven per day.

## Features Used
- Km per day
- Car age
- Service frequency
- Engine type
- Road condition

## Tools Used
- Python
- Google Colab
- Pandas
- Scikit-learn
- Random Forest

## How to Run
1. Open the notebook in Google Colab
2. Run all cells step by step
3. Train the model
4. Make predictions
